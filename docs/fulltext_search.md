# Полнотекстовый поиск в PostgreSQL

## Реализация

В таблице dev.news реализован полнотекстовый поиск по полям
title и content с использованием русского словаря PostgreSQL.

Для ускорения поиска создан индекс GIN idx_news_fulltext_ru.

Заголовкам назначен вес A, основному тексту — вес B.
Результаты сортируются по релевантности с помощью ts_rank.

Поиск выполнен на реальных данных новостного агрегатора.

## Ограничения

1. Поиск ориентирован на слова, а не на смысл текста.
2. Опечатки могут приводить к отсутствию результатов.
3. Синонимы не всегда распознаются автоматически.
4. Для текстов на разных языках могут потребоваться разные словари.
5. GIN-индекс занимает дополнительное место и требует обновления
   при изменении новостей.
6. Сортировка большого количества совпадений по релевантности
   может требовать дополнительных ресурсов.

## Вывод

Полнотекстовый поиск PostgreSQL подходит для базового поиска
новостей по заголовкам и содержимому без отдельного поискового сервера.
Для семантического поиска и устойчивости к опечаткам потребуются
дополнительные механизмы.
